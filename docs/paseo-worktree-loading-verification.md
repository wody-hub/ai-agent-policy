# Paseo worktree 지침 전달 검증

검증일: 2026-11-26. 격리된 임시 Git 저장소를 Paseo 관리 worktree로 열고 각 사례마다 새 세션을 사용했다. 이 결과는 당시 실행 경로와 모델에 한정되며 다른 환경의 자동 로딩이나 도구 수준 강제를 보장하지 않는다.

| 항목 | Codex `gpt-6-luna` | Claude `claude-sonnet-5-5` |
| --- | --- | --- |
| 프로젝트 지침 없는 worktree | 임의 식별자가 없다고 응답. Root·Worker 판단 기준을 설명함 | 미검증: 주간 사용량 제한으로 세션 오류 |
| Git 추적 프로젝트 지침 | `AGENTS.md`에만 있던 무작위 식별자를 정확히 응답 | 미검증: 주간 사용량 제한 |
| 원본 체크아웃의 미추적 지침 | 새 worktree에 `AGENTS.md`·`CLAUDE.md`가 없음. Codex 대조 세션이 식별자 없다고 응답 | 파일 부재 확인; 세션 응답 미검증 |
| 배정 메시지로 명시 전달 | 별도 무작위 식별자를 정확히 응답 | 미검증: 주간 사용량 제한 |

Codex 시험 프롬프트는 파일·셸·검색 호출을 하지 말라고 요청했고, 활동 기록상 프로젝트 지침 및 명시 전달 사례에서 관련 도구 호출은 없었다. 전역 지침 기준 응답은 지침 전달과 일치하지만 부모 맥락 등 다른 전달 경로 가능성을 배제한 독립 증명은 아니다. 작업공간 내 파일 부재는 확인했으나 worktree 이외의 상위 경로에 대한 모든 지침 탐색 동작을 검증한 것은 아니다.

Claude는 한 차례 대조 세션에서 `You've hit your weekly limit · resets Nov 29 at 4am (Asia/Seoul)` 오류가 발생해 나머지 세션을 실행하지 않았다. 제한 해제 후 동일한 대조·추적 `CLAUDE.md`·미추적 원본·명시 전달 사례를 별도 새 세션으로 재검증한다. 세션 도구 호출과 메시지 유입을 확인하며, 프로젝트 지침의 식별자를 시험 질문에 포함하지 않는다.

이 시험은 사용자 소유 프로젝트의 설정·훅·전역 지침을 바꾸지 않았다. 임시 시험 에이전트는 완료 또는 오류 상태 확인 후 archive했다. 시험 worktree 두 개는 사용자 승인 전까지 보존한다.
